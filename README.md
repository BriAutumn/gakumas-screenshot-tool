# 学マス回忆工具

Windows x64 便携工具。解压后双击 `GKMemoryTool.exe`，不需要安装 Python、Node 或配置终端。

启动器图标会按 Windows 的显示缩放比例加载对应尺寸，避免放大小尺寸图标造成模糊。网页标签页使用带内容哈希地址的透明 PNG 图标，更新后会请求新图标。

启动器内容从顶部显示，只有窗口放不下全部内容时才显示滚动条；窗口放大后会自动恢复到顶部。

1. 在启动器中选择 `gakumas.exe`，游戏关闭时点击“安装 / 更新插件”。已有其他 `version.dll` 时不会覆盖。
2. 通过 DMM 启动游戏，进入主页面。插件只读取已加载的本地回忆，不修改游戏数据；每次游戏启动导出一次。
3. 点击“打开模拟网页”，再点“读取最新回忆”。工具自动找到导出文件，转换成 Stage 库，并在下拉菜单选中新库。Produce / 无舞台数据单独显示跳过数量。
4. 选择赛季、支援加成，搜索当前舞台或启动三场轮转。历史结果和导出存在本机，暂停后可续跑。

旧版 `memories.json` 可在启动器的“导入旧导出文件”中选择。新增回忆后重新启动游戏，再读取最新回忆。

原生回忆的“回忆封面”会尽量显示游戏本机缓存的原始玩家照片：仅当导出快照校验一致、且能在固定的 `LocalLow` 照片缓存目录中找到对应文件时才显示，全程只读。缓存缺失、导出为旧版本或文件损坏时，会显示中文说明，不会用其他图片代替。插件调用游戏自身的图片地址格式化方法并导出 `PhotoCacheKey`，封面按该哈希及前两位子目录精确读取，不依赖视觉匹配。旧导出需要使用新版插件重新导出。

回忆使用内置封面时，按原生 `AssetId` 精确读取工具附带、记录过资源哈希的对应回忆封面。玩家照片不会放入分发包；未缓存的照片需先在游戏中打开该回忆，显示后再次打开网页封面预览即可，无需重新导出。

内置封面按游戏的 16:9 展示比例还原，玩家照片保留原始比例。封面预览中的技能卡按原顺序排成一行，名称与自定义强化说明保留在对应卡片下。

数据默认保存到 `%LOCALAPPDATA%\GKMemoryTool`，不在程序目录。移动程序或更新不会删除数据。需要换目录时可用 `--user-home "D:\回忆数据"` 启动工具，并重新安装插件来同步导出位置。

“检查更新”只接受本工具专用发布渠道（GitHub `memory-tool-*` 标签）。完整更新包包含程序、插件、引擎、卡片目录和原生映射，校验后安装到独立版本目录。重启生效，然后在游戏关闭时更新插件。也可安装本地完整 ZIP；“回退上一版本”保留用户数据。在线发布从 1.0.6 起使用此专用渠道；当前已是最新版本时会显示没有更新。

程序/插件与模拟数据是两条不同渠道。启动器“程序更新”里的“检查程序更新 / 安装本地更新包 / 回退上一版本”只处理本工具自身的发布（含程序、插件、以及随包附带的数据），走我们自己的 GitHub Releases，需要维护者构建发布新版。模拟数据（引擎、卡片目录、原生映射与图标）则直接从 GKTools 官方仓库和公开原生 ID 数据源获取，常规更新无需我们重新打包 EXE，由“同步上游数据 / 回退模拟数据”单独处理：先检查上游，没有变化时显示已是最新；有新版本时只显示将要安装的数据版本（SHA）与变更摘要，确认后后台下载、校验并原子安装到独立版本目录。失败会给出明确错误，绝不会在无法检查上游时误报“已是最新”，也不会静默回退到内置数据。

安装或回退模拟数据前，工具会确认没有正在运行的搜索 / 模拟 / 赛季任务，并暂时禁止启动新任务；已经在跑的搜索会继续用它启动时固定的那份数据跑完。安装、回退完成后需要重启工具才生效；重启后再点“读取最新回忆”，会按新的原生映射重新生成本地快照，旧的结果与历史仍归属它们当初使用的数据版本，不会被新数据错误地续跑。同一进程在生命周期内始终使用固定的数据版本，磁盘上的活动指针变化只影响下一次启动。回退可随时切回上一份已安装数据，用户数据不受影响。

每次游戏启动后由插件导出回忆；同步器只下载公开的上游资源，不上传本机回忆或账号数据。回忆导入只读取插件按固定格式导出的本地数据。官方上游若出现当前程序还不认识的全新机制，仍可能需要等本工具更新适配，这类未知内容目前不受支持，也不会被当作已兼容。

活动与联赛暂不支持。搜索是采样筛选，不保证理论最高分。原生映射存在少量尚未完成效果独立核验的候选对应，能执行模拟不等于所有效果已逐项证实；不支持的新 ID 会明确报错并保留原始导出。

关闭启动器会取消运行中的搜索并保存进度。卸载插件只移除本工具拥有的 DLL / 配置，修改过或其他工具的文件会保留。

如果更新文件损坏，运行 `GKMemoryTool.exe --baseline` 可直接打开原版进行回退。不要只复制 EXE，保留整个解压目录。

开发：Python 3.13，`PYTHONPATH=src python -m unittest discover -s tests`。运行 `python packaging/entry.py`；构建 `python packaging/build_windows.py`（需 PyInstaller 6.20 和 Visual Studio 2022 Build Tools）。原生插件编译见 `tools/native-memory-export/build.cmd`。
