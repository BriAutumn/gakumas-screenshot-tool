# GKTool 2026.09.20 先行版

完整解压后双击 **GKTool-preview.exe**。首次使用请打开同目录 **使用说明.html**，配图已内嵌，可以离线阅读。

本版整合四步工作台、采集与离线识别页签、记忆库查找及状态筛选、高 DPI 调整，以及本地模拟的分轮初筛、角色均衡复测和三舞台状态导航。日文 OCR 短文字处理与详情规则同步更新；未确定字段仍须核对，不会自动当作无强化。

内置 Python、Node、OCR/ONNX 运行库和模型；无需安装开发环境或填写 API 密钥。模拟网页仅使用本机浏览器及 127.0.0.1。

用户原图、记忆库、配置和模拟结果默认保存在 `%LOCALAPPDATA%\GKTool`，与程序目录分开。更新时解压到新目录即可；请保留并备份用户数据目录。此包不携带开发者的个人截图或记忆库。

这是供先行使用的版本：完整批次识别评估尚未完成，不承诺所有截图均能自动正确识别，也不宣称达到 90% 或 100%。遇到待解决项请使用记忆库核对。正式使用前先试采一份，确认游戏窗口与采集区域设置正确。

如启动异常，点击工作台的“运行诊断”，查看日志目录中的 `diagnostics.json`、`desktop.log` 或 `startup-error.txt`。关闭浏览器不会停止模拟服务，请从服务窗口停止。不要只复制 exe，必须保留整个解压目录。

图标、游戏素材和模型来源见 `_internal/THIRD_PARTY.md`，依赖及许可清单位于 `_internal`。本版未签名，干净 Windows 虚拟机及不同显示缩放下的验证仍待补充。
