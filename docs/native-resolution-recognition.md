# 原始分辨率回退识别

当常规识别未通过置信度核验时，程序从保存的原始截图重新裁剪目标区域，并加载素材库中的原始 PNG 模板比对。不会把 48×48 / 64×64 小图放大后当作新的清晰证据。

- 道具：比较本地素材库中可用的竞技场道具图案，再验证普通 / 强化标记。只有一种版本的道具另做完整内部图案核验。
- 卡片：原图图案和普通强化标记需通过核验，且独立读取的卡名必须一致。原先清楚读出的冲突卡名会阻止自动接受。
- 属性数字：缺失或只有一次有效读数时，从原图重读；仍要求两次一致，且不覆盖已读出的不同数字。
- 自定义强化：不清楚的中央绿色角标从原图重查；详情页文字未读齐时，从原图面板重新读取，并保留两种尺度的一致性、绿色文字覆盖和详情归属检查。

图案匹配会小范围调整模板的尺寸和位置以适配截图。参考素材本身只有约 130 像素时，原图模式无法创造更高清的细节。来源裁剪不足 80 像素的图案也不会因放大而获得“原图高置信度”。

常规识别已通过的字段保留原结果。失败的回退记录也保存在识别报告中，包括源图坐标、像素尺寸、原始模板尺寸、匹配误差和拒绝原因。原始截图、旧结果库和人工核对记录保留；每次离线处理写入独立的新结果库。

原图回退解决的是图像信息损失和部分对齐问题。缺少自定义强化效果规则、截图没有包含目标、无法确定卡槽或详情归属时，仍保留未解决状态，不把未知强化写成无强化。

当前目录中另有 8 个竞技场道具 ID（478–483、485–486）没有图标模板，属于 4 个完整缺失的图案家族；现有已加载的图案家族没有缺少另一版本的情况。这些缺失素材仍需补充，原图回退本身不能补出模板。
