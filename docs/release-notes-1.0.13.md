# 学マス回忆工具 1.0.13

修复部分电脑“插件已安装，但没有新导出”的问题，并修正早期后台启动可能触发 `Fatal error in GC: collecting from unknown thread` 的时序。

- 自动后台启动，保留代理调用备用路径；两条路径只启动一次导出。
- 等待本游戏的晚启动模块信号后才访问 IL2CPP，先注册线程、再枚举程序集；线程正常退出时注销一次。
- 总等待上限三分钟，线程创建最多尝试三次；失败保留旧成功导出，过期读取状态明确提示。
- 保留 version.dll / winhttp.dll 自动共存选择，不覆盖其他插件；所有汉化版本并未逐一实测。
- 包含 V3 诊断收集脚本，不收集 memories.json、密码或令牌。

## 安装或升级

完整解压 ZIP 后运行 GKMemoryTool.exe。旧版用户可点击“检查程序更新”；更新完成后，先关闭游戏，再点击“安装 / 更新插件”，随后启动游戏进入主界面。无需清空旧数据。等待时间从游戏启动计算，停留在标题页的时间也计算在内。

使用过 1.0.12 测试包的用户请停用并升级。本包界面保留“启动修复测试版”字样和诊断日志，Release 为正式更新渠道，旧版更新器可以发现。

## 验证范围

本机真实游戏正常启动并成功导出 417 份，数量与文件 SHA256 一致。约 96 秒包含进入主界面的等待时间，实际枚举约 15 毫秒。已验证缺少就绪信号时不调用 IL2CPP、线程注册失败不进入元数据访问、注销只执行一次，以及超时、重试上限、旧快照保护、两个入口转发和完整包自检。不同电脑与汉化组合仍可能存在差异；失败时运行包内 GKMemoryExport-diagnostic-v3.cmd 提供生成报告即可。
